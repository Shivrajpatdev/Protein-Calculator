# 🥗 Protein Calculator

A clean, beginner-friendly web app that estimates how much protein is in a given amount of food.

## ✨ Features

- Select from 30 common foods
- Enter the food amount in grams
- Instantly calculate estimated protein
- Includes meat, seafood, dairy, legumes, vegetables, fruits, grains, nuts and seeds
- Responsive design for mobile and desktop
- No frameworks or external libraries
- Works directly in a browser

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript

## 🚀 Run Locally

No installation is required.

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Select a food.
4. Enter the amount in grams.
5. Click **Calculate**.

## 🌐 Deploy with GitHub Pages

1. Push the project to a GitHub repository.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under the deployment/source option, choose the branch containing `index.html` (usually `main`) and the root folder.
5. Save the settings.
6. GitHub will provide a public website link after deployment.

## 📊 Nutrition Data

The calculator uses approximate protein values per 100 g as a reference. Nutrition values can vary depending on food variety, brand, raw/cooked state, water content and preparation method.

The project follows the general FoodData Central convention of reporting nutrient values on a 100 g edible-food basis. For some foods in this beginner database, the label explicitly indicates a cooked or dry state.

For authoritative nutrition information, see the [USDA FoodData Central](https://fdc.nal.usda.gov/) database.

**Important:** This tool is for general educational estimation and is not medical or dietary advice.
